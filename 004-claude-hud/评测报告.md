## 🎯 产品定位

**一句话描述**: Claude Code 插件，实时显示会话状态（上下文使用率、活跃工具、运行中的子代理、TODO 进度）

**目标用户**: 
- Claude Code 重度用户
- AI 编程工作流优化者
- 需要实时反馈的开发者

**解决痛点**:
1. 上下文窗口使用率不透明 → 容易突然超限
2. 工具调用无实时反馈 → 不知道 AI 在做什么
3. 子代理状态不可见 → 难以追踪并行任务
4. TODO 进度无可视化 → 任务完成度不清晰

## 🏗️ 技术架构

### 核心组件

```
┌─────────────────────────────────────────────────────────┐
│                    Claude Code CLI                       │
│  (stdin JSON → transcript JSONL → stdout)               │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│                    claude-hud                            │
│  - 解析 transcript JSONL                                 │
│  - 提取工具/代理/TODO 活动                               │
│  - 计算上下文使用率                                      │
│  - 查询 Usage API (Pro/Max/Team)                        │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│              statusLine API (原生集成)                   │
│  - 多行/单行布局                                         │
│  - 彩色进度条                                            │
│  - 实时更新 (~300ms)                                     │
└─────────────────────────────────────────────────────────┘
```

### 数据流

1. **输入**: Claude Code 的 transcript JSONL (工具调用、代理状态、TODO 更新)
2. **处理**: 
   - 解析 JSONL 流
   - 计算上下文使用率 (从 Claude Code 原生数据)
   - 查询 Usage API (缓存 TTL: 60s)
3. **输出**: statusLine 格式字符串 (支持 ANSI 颜色)

### 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 集成方式 | statusLine API | 原生支持，无需额外窗口 |
| 上下文数据 | 原生 API | 准确，非估算 |
| 更新频率 | ~300ms | 平衡实时性与性能 |
| 配置存储 | ~/.claude/plugins/claude-hud/config.json | 符合 Claude Code 插件规范 |

## 💡 创新点

### 1. 原生状态线集成
- 无需 tmux/分屏
- 任何终端都支持
- 零学习成本

### 2. 精确上下文监控
- 直接从 Claude Code 获取 token 数据
- 支持 1M 上下文窗口
- 可视化进度条 (绿→黄→红)

### 3. 多层级可视化
- **Line 1**: 模型 + 项目路径 + Git 分支
- **Line 2**: 上下文条 + 使用率限制
- **Line 3+**: 工具活动 / 代理状态 / TODO 进度

### 4. 高度可配置
- 3 种预设 (Full/Essential/Minimal)
- 20+ 配置项
- 支持自定义颜色

## 🔧 技术亮点

### 1. 性能优化
```javascript
// Usage API 缓存策略
{
  "cacheTtlSeconds": 60,        // 成功响应缓存 60s
  "failureCacheTtlSeconds": 15  // 失败响应缓存 15s
}
```

### 2. Git 状态增强
```
# 支持多种显示模式
git:(main)                    # 基础
git:(main*)                   # 未提交变更
git:(main ↑2 ↓1)              # 前后方差异
git:(main* !3 +1 ?2)          # 文件统计 (!修改 + 新增？未追踪)
```

### 3. 跨平台兼容
- macOS/Linux/Windows
- 处理 Linux tmpfs 问题 (TMPDIR  workaround)
- 支持代理配置 (HTTPS_PROXY)

## ⚠️ 局限性

1. **依赖 Claude Code**: 仅支持 Claude Code CLI
2. **订阅限制**: Usage 显示仅限 Pro/Max/Team
3. **平台限制**: Linux 安装需要 TMPDIR workaround
4. **功能边界**: 仅显示状态，无控制能力
